# Executive Dark Portfolio Package

This package contains a refined version of your GitHub Pages home with a more executive landing-page style and dark professional cards.

## Files

- `index.md` → executive dark homepage
- `PROFILE-README.md` → profile README for repository `ajmarzola`
- `assets/executive-banner.svg` → visual banner
- `_config.yml` → GitHub Pages basic config
- `cv/Anderson_Marzola_CV.pdf` → placeholder file for your real CV

## Recommended Usage

1. Copy `index.md`, `_config.yml`, `assets/` and `cv/` to `ajmarzola.github.io`
2. Replace the placeholder CV with your actual PDF using the same name
3. Copy `PROFILE-README.md` into the repository named `ajmarzola` as `README.md`
4. Replace placeholder LinkedIn and email values
5. Update each project card with the exact repository links

## Positioning Goal

This version is designed to look more curated, premium and architecture-focused, reinforcing:
- technical leadership
- enterprise software experience
- cloud-native portfolio direction
- a stronger recruiter-facing first impression
